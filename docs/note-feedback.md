# Pick feedback

Registered notes now produce a brief pale fret flash that settles into the
lane color, a small fret-cap lift, and a fading vibration glint along the
struck string. Quiet notes get the same clear feedback once detected.

The existing spark pool now emits four short, local sparks per hit instead of
eight long travelling sparks. String glints use six small reusable line meshes,
hidden when idle. Animation uses elapsed time; reduced motion suppresses the
new vibration and cap lift. Changing songs clears the fret feedback.

This changes only visual feedback in the highway. Audio routing and note
detection are unchanged.
